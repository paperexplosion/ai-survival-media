# TENKU Note Pro AI 15万円の10型2in1

![カバー画像](/blog-images/product-20261006-tenku-note-pro-ai/cover.jpg)

## TENKU Note Pro AIは何を発表したのか

![TENKU Note Pro AIの主な仕様と価格](/blog-images/product-20261006-tenku-note-pro-ai/fig-1.svg)

*図：TENKU Note Pro AIの主な仕様と価格（出典：[1][7]）*

「TENKU Note Pro AI」は、10.5インチのディスプレーを搭載した小型の2in1ノートPCです[1]。360度ディスプレー回転型で、タッチ操作とペン操作に対応しています[1]。

主な仕様は次のとおりです。

![TENKU Note Pro AIは何を発表したのかのイラスト](/blog-images/product-20261006-tenku-note-pro-ai/ill-1.jpg)

- OSはWindows 11 Pro、プロセッサーはCore Ultra 5 125U[1]
- メモリーは16GB、ストレージは512GB[1]
- ディスプレーは10.5インチIPS液晶、1920×1280ドット、10点マルチタッチ対応、ペン対応[1]
- インターフェースはUSB Type-C×2と3.5mmコンボジャック×1[1]
- 無線通信はWi-Fi 6とBluetooth 5.2に対応[1]
- 本体サイズは243×177.6×17.5mm、重量は960g[1]
- バッテリーは3800mAhを内蔵[1]

価格については、通常価格17万6800円、キャンペーン価格15万9120円とする情報があります[1]。一方、通常価格176,800円、9月24日まで発売記念価格132,600円で販売されているとする情報もあります[7]。販売開始は9月18日とされています[7]。

対応地域や発売時期の詳細は、出典からは確認できません。価格やキャンペーンの条件は時期によって変わる可能性があるため、購入を考える際は最新の情報を確認しておきたいところです。

## TENKU Note Pro AIの主な機能とスペック

![TENKU Note Pro AI バッテリー駆動時間の目安](/blog-images/product-20261006-tenku-note-pro-ai/fig-2.svg)

*図：TENKU Note Pro AI バッテリー駆動時間の目安（出典：[1][7]）*

TENKU Note Pro AIは、Windows 11 Proを搭載した10.5インチの小型ノートPCです[1]。ディスプレーはIPS液晶で1920×1280ドット、10点マルチタッチとペン操作に対応します[1]。別の集計では10.51型・3:2比率のタッチ対応ディスプレーとされています[7]。

本体サイズは243×177.6×17.5mm、公称重量は960gです[1]。実測では944.5gとされており、約950gとする紹介もあります[1][7]。筐体にはアルミニウム合金が使われています[1]。

360度回転する2in1構造で、ノートブックモード、プレゼンモード、タブレットモードなどに変形できます[1]。Microsoft Pen Protocol対応のスタイラスが使え、4096段階の筆圧検知に対応します[1]。Surface Pen互換のスタイラスを利用できるという説明もあります[7]。

![TENKU Note Pro AIの主な機能とスペックのイラスト](/blog-images/product-20261006-tenku-note-pro-ai/ill-2.jpg)

CPUはCore Ultra 5 125U、メモリー16GB、ストレージ512GB SSDを搭載します[1][7]。ストレージはM.2 2280 PCIe SSDで、ユーザー自身で換装できるとされています[1]。インターフェースはUSB Type-C×2と3.5mmコンボジャック×1、無線はWi-Fi 6とBluetooth 5.2に対応します[1]。Webカメラは200万画素です[1]。

バッテリーは3800mAhで、駆動時間は最大約17時間、ローカルビデオ再生時は約7時間、オンラインビデオ再生時は約3～4時間、高負荷作業時は約1～2時間とされています[1]。キーピッチは約17.8mm、キーストロークは実測約1.5mm、タッチパッドは91×54mmです[1]。Copilotキーは搭載されていません[1]。

価格は通常176,800円で、発売記念価格として132,600円で販売された時期もありました[7]。別の記事では17万6800円、キャンペーン価格15万9120円とされています[1]。

持ち歩く道具は、軽さだけでなく「どこに収まるか」で選んでしまうものかもしれません。

## 競合と比べてTENKU Note Pro AIは何が違うのか

![小型2in1とミニPCの設計思想の違い](/blog-images/product-20261006-tenku-note-pro-ai/fig-3.svg)

*図：小型2in1とミニPCの設計思想の違い（出典：[1][2][7]）*

10型クラスの小型2in1という市場は、選択肢がもともと多くありません。TENKU Note Pro AIは、10.5インチのディスプレーと960gの本体を備えた360度回転型の2in1 PCです[1]。同じ10型クラスで比較できる競合は限られますが、まずはサイズと価格の位置づけを整理します。

TENKU Note Pro AIの通常価格は17万6800円、キャンペーン価格は15万9120円です[1]。別の集計では、通常価格17万6800円、発売記念価格13万2600円とされています[7]。価格の記載が媒体によって異なるため、販売時期や条件による違いとされています。

![競合と比べてTENKU Note Pro AIは何が違うのかのイラスト](/blog-images/product-20261006-tenku-note-pro-ai/ill-3.jpg)

CPUはCore Ultra 5 125U、メモリー16GB、ストレージ512GBです[1]。この構成は、いわゆるCopilot+ PCの要件とは異なります。Copilot+ PCはQualcommのSnapdragonチップとMicrosoftのCopilot+を組み合わせた製品として登場しており[2]、TENKU Note Pro AIはCopilotキーも搭載していません[1]。AI機能の前提が同じではない点は、比較の際に見落とされやすいところです。

一方、ミニPCと呼ばれる小型デスクトップは、約3Lの筐体にRTX 5090 Laptop GPUを載せた120万円のモデルや、最大192GBメモリで300B級LLMのローカル実行を訴求する製品などが登場しています[7]。設置面積の小ささよりも処理能力を優先する方向の製品群です。TENKU Note Pro AIは、持ち運べる10.5型とタブレット変形を軸にしており、据え置きの小型機とは狙いが分かれます。

小型2in1、Copilot+ PC、ミニPCは、それぞれ「軽さ」「AI機能の前提」「処理能力」という別の価値を中心に設計されています。あなたが持ち歩くのか、机に置くのかで、同じ「小さい」でも意味は変わってきます。

## TENKU Note Pro AIを使うと仕事と遊びはどう変わりそうか

![TENKU Note Pro AIの仕事と遊びを支える数字](/blog-images/product-20261006-tenku-note-pro-ai/fig-4.svg)

*図：TENKU Note Pro AIの仕事と遊びを支える数字（出典：[1]）*

10.5インチのディスプレーを搭載し、本体重量960gの「TENKU Note Pro AI」は、360度ディスプレー回転型の2in1 PCです[1]。ノートブックモード、プレゼンモード、タブレットモードに変形できるため、外出先での作業と動画視聴という二つの場面を、一台で切り替えて使える可能性があります[1]。

カバンに入れて持ち歩く場面を想像してみましょう。本体サイズは243×177.6×17.5mmで、ボディーバッグに入るサイズ感とされています[1]。カフェや移動中の電車内でキーボードを開けば、Windows 11 ProとCore Ultra 5 125Uを搭載した環境で、資料作成やメールの返信といった作業ができそうです[1]。メモリーは16GB、ストレージは512GBです[1]。

作業が一段落したら、ディスプレーを回転させてタブレットモードに変えると、動画視聴にも使えそうです[1]。ディスプレーは10.5インチのIPS液晶で1920×1280ドット、10点マルチタッチに対応し、ペン操作にも対応しています[1]。Microsoft Pen Protocol対応のデジタルスタイラスペンを使えば、4096段階の筆圧検知により、コンパクトなお絵かきタブレットとしても活用できるとされています[1]。

![TENKU Note Pro AIを使うと仕事と遊びはどう変わりそうかのイラスト](/blog-images/product-20261006-tenku-note-pro-ai/ill-4.jpg)

バッテリー駆動時間は、最大約17時間、ローカルビデオ再生時は約7時間、オンラインビデオ再生時は約3～4時間とされています[1]。外出先で長時間の動画を楽しむ場合は、再生方法によって持ちが変わる点に注意が必要かもしれません[1]。ストレージにはM.2 2280 PCIe SSDが採用されており、ユーザー自身で換装可能です[1]。

なお、この製品はCopilotキーが搭載されていません[1]。キーボードは78キーの日本語配列で、キーピッチは約17.8mm、キーストロークは実測約1.5mmを確保しています[1]。タッチパッドも91×54mmと比較的大きめです[1]。

一台で作業とくつろぎの両方を担うという発想は、荷物を減らしたい人にとって、どこまで現実的でしょうか。

![TENKU Note Pro AIの気になる点と日本での意味のイラスト](/blog-images/product-20261006-tenku-note-pro-ai/ill-5.jpg)

## 編集長の眼

10.5インチ、960gのボディにWindows 11 ProとCore Ultra 5を詰め込んだTENKU Note Pro AIは、荷物を減らしたい人にとって魅力的な一台です。カフェでキーボードを開いて資料を作り、そのままディスプレーを回してタブレットモードに切り替え、ペンで手書きメモを取る。移動中の電車で動画を楽しむ。そんな一日の流れを、これ一台で担えるかもしれません[1]。M.2 2280 PCIe SSDを自分で換装できる点も、長く付き合う道具としての余地を感じさせます[1]。一方で、Copilotキーが非搭載であること[1]、USB Type-C×2と3.5mmジャックのみというインターフェース[1]は、AI機能や周辺機器を重視する人には物足りない面もあるでしょう。それでも、10型クラスの小型2in1という選択肢が増えること自体が、持ち歩く道具の幅を広げてくれます。軽さと変形、そしてペン。この組み合わせが日常のどこに収まっていくのか、これから見ていくのが楽しみです。
