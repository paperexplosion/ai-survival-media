# AI vs AI 資格試験バトル (HR001-01)

AI実験室 vol.1 の実験データと再現手順。

## 実験概要

4つのAIモデル（Gemini, Claude, GPT-4o, DeepSeek）に、3つの国家資格の過去問を同一条件で解かせ、正答率と合格判定を比較した。

## 使用資格

| 資格 | 出典 | 回 | 問数 | 合格基準 |
|------|------|------|------|--------|
| FP3級（学科） | 日本FP協会 公式サイト | 2026年5月公表分 | 60問 | 36問正解（60%） |
| 宅地建物取引士 | 不動産適正取引推進機構 | 令和7年度 | 50問 | 33問正解（66%） |
| ITパスポート | IPA 公式サイト | 令和8年度公開問題 | 100問（88問使用*） | 正答率60%以上 |

*ITパスポートはスキャンPDFのためOCR抽出。11問はOCRパース不良、1問は図表問題のため除外。

## 使用モデル

| モデル | 指定した model_id | APIが返したバージョン | temperature |
|--------|------------------|---------------------|-------------|
| Gemini | gemini-3.6-flash | gemini-3.6-flash | 0 |
| Claude | claude-sonnet-5-5 | claude-sonnet-5-5 | 0 |
| GPT-4o | gpt-4o | gpt-4o-2024-08-06 | 0 |
| DeepSeek | deepseek-chat | deepseek-flash | 0 |

Geminiは思考トークンを出力に含む仕様のため、出力上限を他の3モデルの50トークンから1024トークンに広げている。回答内容（選択肢の番号だけを答える）、問題文、プロンプト、temperature=0は4社で同一。

DeepSeek API はリクエスト時 `deepseek-chat` を指定しているが、レスポンスのモデル名は `deepseek-flash` を返す。記録には API が返した実際の名前を使用する。

## 結果サマリ

| モデル | FP3級 (60問) | 宅建 (50問) | ITパスポート (88問) | 総合正答率 |
|--------|-------------|-----------|-----------------|------|
| Gemini | 60/60 (100.0%) **合格** | 44/50 (88.0%) **合格** | 82/88 (93.2%) **合格** | 93.9% |
| Claude | 36/60 (60.0%) **合格** | 48/50 (96.0%) **合格** | 72/88 (81.8%) **合格** | 78.8% |
| DeepSeek | 48/60 (80.0%) **合格** | 24/50 (48.0%) 不合格 | 77/88 (87.5%) **合格** | 75.3% |
| GPT-4o | 42/60 (70.0%) **合格** | 27/50 (54.0%) 不合格 | 75/88 (85.2%) **合格** | 72.7% |

3資格すべてに合格したのはGeminiとClaudeの2つだけ。DeepSeekとGPT-4oは宅建で不合格。

## プロンプト（全モデル共通）

```
あなたは資格試験の受験者です。以下の問題を読み、最も適切な選択肢の番号だけを答えてください。
解説は不要です。選択肢の番号（1〜4）だけを回答してください。

---
{問題文と選択肢}
---

回答：
```

（FP3級の○×問題、ITパスポートのア/イ/ウ/エは各資格の形式に合わせて変更）

## 採点ルール

1. モデルの出力から回答を抽出（数字/記号の最初の出現）
2. 公式解答と完全一致で正解
3. 解析不能な回答は「無効（INVALID）」として不正解扱い
4. 1モデルにつき各資格1回のみ

## 再現手順

```bash
# 1. 過去問PDFを各資格の公式サイトからダウンロードし data/ に配置
# 2. 問題テキストを抽出
python3 scripts/extract_questions.py

# 3. 実験実行（APIキーを各 .env に設定済みであること）
python3 scripts/run_experiment.py

# 4. 集計
python3 scripts/score_aggregate.py out/results_*.csv

# 5. グラフ生成
python3 scripts/generate_charts.py
```
